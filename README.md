# StaffSync — Modern Human Resource Management Solution

A responsive MERN-stack student project for employee directory, attendance, leave requests, announcements, and learning.

## Run frontend
1. Install Node.js.
2. In a terminal: `cd frontend`
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL shown by Vite. The dashboard works with demo data.

## Run backend
1. Install and start MongoDB.
2. Copy `backend/.env.example` to `backend/.env`.
3. In a terminal: `cd backend && npm install && npm run dev`
4. API runs at `http://localhost:5000/api`.

Frontend: React + Vite. Backend: Node.js + Express. Database: MongoDB/Mongoose.
This is a student demo; add authentication, authorization, validation, and security controls before real use.
